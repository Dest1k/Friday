# Презентации: объединённый исходный ремонт Source116

Статус этого блока — **SOURCE_ACCEPTED_NOT_INSTALLED**. Публикация сохраняет
проверенные исходники и не меняет установленную версию. Для Source116
**native runtime, Office, Telegram и пользовательская семантическая приёмка
остаются UNPROVEN**. Исходная реализация, установка и работа у пользователя —
отдельные факты.

В блоке шесть точных native-модулей и ссылка на седьмой, уже опубликованный
`tools/scoped_presentation.py` в
[V01 reader](../../2026-10-31/v01-presentation-reader-source/README.md).
Его байты совпадают; повторной копии нет. `manifest.json` указывает исходные
имена модулей, SHA-256 до/после, размер и режим `100644`. Это снимки для анализа,
а не самодостаточная установка: соседние продуктовые зависимости не копируются.

Объединение сохраняет typed XLSX reader и прежний literal table writer
[Source115](../../2026-10-31/literal-table-source-repair/README.md), добавляя
ограниченные native PPTX/ODP чтение, создание и адресное редактирование.
PPTX создаётся из поддержанной таблицы Orders: пять слайдов, одна native-таблица,
одна диаграмма с отдельной вложенной XLSX. Редактирование связывает точный заголовок,
категорию, старое значение и вложенную книгу; остальные части пакета сохраняются.
ODP содержит native страницы, таблицы, диаграммы и отдельные заметки; поддержано
адресное редактирование одной простой числовой ячейки без перезаписи источника.
Неоднозначные заголовки, неподдержанные структуры, внешние связи, активный XML
и небезопасные архивы отклоняются. Объединённая подсказка имеет revision v15.

В исходниках также есть ограниченный Office conversion путь `pptx_pdf`,
`odp_pptx`, `pptx_odp`. Здесь проверены только точные аргументы и имена фильтров.
Наличие кода не доказывает запуск фильтра, успешный экспорт, визуальную точность
или обычное открытие/сохранение/повторное открытие в Office.

Переносимые проверки запускаются стандартным Python из этого каталога:

```sh
python3 -B controls.py
```

Все 18 проверок прошли; результат сохранён в `controls-result.json`. Они проверяют
точные хеши, синтаксис всех семи модулей и неизменность наследованного table writer;
исполняют точные pure writer, ранее опубликованный reader и объединённый native
dispatch. Нейтральные PPTX/ODP/XLSX создаются только в памяти. Проверяются native
части, данные диаграммы и вложенной книги, адресность изменений, сохранение
остальных частей, XLSX literal/formula/cache разделение, typed отказы, ошибочные
старые значения, неоднозначные заголовки и небезопасные входы.

Эти проверки не загружают установленное приложение, не исполняют authority-слой
и не подменяют capability
положительным mock, не запускают Office, модель, сеть или сообщения. Полные
неизменные исходные и независимые проверки объединения переиспользованы;
`manifest.json` сохраняет только безопасные хеши их результатов. Пересекающиеся
счётчики source/merge/consumer проверок не складываются в число независимых
пользовательских испытаний.

Чтение показывает native XML и сохранённые данные, без вычисления формул,
обновления диаграмм, рендеринга, OCR и оценки layout/style inheritance.
Синтетический ODP не доказывает сохранение произвольного оригинального ODP.
Семейство из 15 форматов, 161 native-операции и 10 конверсий остаётся
**UNACCEPTED**; общая продуктовая приёмка из этого блока не следует.

Tester остаётся отдельным source-only кандидатом и сюда не включён; его
публикация или принятие не подразумевается. Приватные installer, service,
custody, handoff, runtime и пользовательские материалы исключены. Архивы
примеров не сохраняются. Стандартные namespace URI и постоянные пути sandbox
в исходниках описывают формат и механизм исполнения. Общие диапазоны RFC1918
в сетевой проверке — константы политики, а не адреса развёртывания.
`SHA256SUMS` покрывает все файлы этого блока, кроме самого списка.
