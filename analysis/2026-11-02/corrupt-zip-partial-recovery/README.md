# Повреждённый ZIP: явное восстановление здоровых файлов

Статус: **SOURCE_ACCEPTED_NOT_INSTALLED**. Блок содержит четыре точных связанных
исходника и патч относительно установленной Source151. Эта публикация сохраняет
принятое исправление для будущей версии. Исходный A12 FAIL установленной Source151
остаётся результатом baseline. Обычная identity, установка и Telegram-приёмка
нового поведения ещё не подтверждены.

При повреждении данных одного ZIP-member чтение показывает проверенный список
здоровых файлов и повреждённые элементы с `archive_complete=false`. Восстановление
требует явного `allow_partial=true`, незашифрованного ZIP без пароля и новой папки.
Результат содержит `success=false`, `published_partial=true`,
`effect_disposition=known_partial`, точные восстановленные пути и явное сообщение
о неполноте. Повреждённые файлы не публикуются; при отсутствии здоровых файлов
папка не создаётся. Обычное извлечение сохраняет строгий режим.

Пропускать разрешено только типизированные ошибки ограниченного распаковывания
или CRC содержимого. Ошибки заголовков, имён, пересечений, путей, ссылок,
дубликатов, структуры, шифрования, лимитов, отмены и владения остаются отказами
всего действия. Проверка вместимости предшествует публикации. Ошибка после
публикации сохраняет UNKNOWN. Четыре файла применяются вместе: новый тип ошибки,
архивный путь, описание инструмента и публичный footer.

Повторно используются 41 исходная проверка автора и 13 независимых проверок
Кими без замечаний. Они проверяют разбор, файловый pipeline и ближайших
потребителей на изолированных адаптерах; не доказывают обычную identity.
`manifest.json` сохраняет безопасные хеши результатов и точный оставшийся
runtime-сценарий. Эти наблюдения не складываются с пользовательскими PASS.

Переносимая проверка: `python3 -B controls.py`. Она проверяет хеши и синтаксис
всех четырёх файлов, исполняет чистый ограниченный ZIP-reader на нейтральных
архивах в памяти и различает повреждение payload, структурный отказ и лимит.
Полное приложение и authority-слой не загружаются. Снимок требует остальных
зависимостей продукта и не является самостоятельной установкой.

Приватные запросы, runtime, custody, installer, handoff и файлы пользователей
в блок не включены. Постоянные диапазоны адресов в исходнике являются общими
константами сетевой политики. `SHA256SUMS` покрывает весь блок, кроме себя.
