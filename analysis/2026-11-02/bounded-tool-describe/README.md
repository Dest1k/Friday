# Bounded tool descriptions — accepted source candidate

An installed baseline run produced a 174,912-character `write_file` description. The normal result budget persisted it privately; the following generated cache-read call was refused by the privacy boundary. The original user-task failure remains recorded.

This one-file candidate returns oversized descriptions as exact JSON fragments with a full-response SHA-256, offsets and explicit continuation/coverage fields. A literal query can locate an operation without walking every page. Small default responses remain byte-identical. Continuation requires a matching current scoped schema; changed or removed scope refuses stale fingerprints. Existing bridge dispatch and privacy boundaries remain in force.

Default pages are bounded below the existing 8,000-character minimum result budget. Lower custom thresholds and an over-budget aggregate of unrelated calls can still spill. The candidate neither increases budgets nor grants access to private cache paths. It does not establish the exact cause of the separate presentation-task refusal or repair historical replay effects.

The unchanged candidate passed 18 author controls and 10 independent controls. The latter reconstructed the real full JSON through 146 bridge pages, checked native inline storage, targeted lookup, Unicode/escaping, stale scope, invalid arguments and small-response compatibility. The grouped observations in `control-results.json` are source controls with explicit fixture seams; they are not installed, normal-identity, model or Telegram acceptance. No model call or shared runtime write was made by those controls.

`source/tools/tool_search.py` contains the exact reviewed candidate. The patch targets `tools/tool_search.py` at the preimage SHA in `manifest.json`; apply it only to matching bytes and perform the required runtime qualification before a future installation. This publication does not alter the installed Source151 baseline. Original failures, unknown outcomes and the full 170-case/120-format matrix remain unchanged.
