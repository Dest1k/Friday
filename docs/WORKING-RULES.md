# Правила работы с владельцем

Действуют с 2026-11-07.

- Отвечать коротко. Не пересказывать процесс и ход мыслей.
- Отвлекать владельца только когда без него работа невозможна.
- Всё остальное решать самостоятельно в согласованных пределах.
- Писать в чат только по делу: существенные находки, блокеры, промежуточные и итоговые
  отчёты. Мелкие технические шаги в чат не выносить — они остаются в рабочих материалах.
- Язык общения в чате — русский (включая отчёты, блокеры и находки).
