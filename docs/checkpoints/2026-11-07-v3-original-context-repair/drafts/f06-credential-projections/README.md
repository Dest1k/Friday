# F06: проекция полей пароля — проверенный исходный кандидат

Пять файлов закрывают известное дублирование паролей `read_file` и защищённого
`write_file` в новых записях БД, tool calls и trajectory, предупреждениях о ремонте
JSON и предпросмотре аргументов. Живые аргументы, содержимое пользовательских
документов, идентификаторы и сохранение времён сообщений остаются прежними.
Логи ремонта файловых вызовов скрывают аргументы целиком, включая повреждённый JSON.

Оригинальная директива, строка99, допускает ввод тестового пароля в обычном
приватном сообщении и сохранение исходного чата. Эта правка не удаляет историю
и не доказывает отсутствие эха в будущих ответах, поиске, summaries или памяти.
Известные ошибки и предыдущие проверяющие сохранены по ссылкам в CANDIDATE.json.

Это исходный кандидат после независимого review и проверки точного применения
patch к пяти настоящим preimages в малом изолированном каталоге. Файлы продукта
не менялись; слой, install receipt и пользовательская приёмка не созданы.
Перед установкой нужны штатная композиция от фактического преемника205,
проверки consumer/rollback и свежий допуск Root. Исторические204/205 gates не
повторялись и не переносятся на этот кандидат. Общий объём170/120/B00 остаётся.
