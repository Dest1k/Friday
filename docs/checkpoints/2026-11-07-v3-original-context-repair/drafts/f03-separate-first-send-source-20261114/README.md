# F03: отдельный ещё не выполненный первый send — исходники

Source-only материалы для ревью. Установленная221 не менялась. Операция, новый
clock/grant, модель, Office и отправка из этой публикации не запускались.

Оригинальный run остаётся PREPARED/none/attempts0; original300 и прежний600 истекли.
Отдельный конечный недостающий шаг требует решения Root и свежего полного допуска;
старый issuer, Runner.new, generic resume и сброс часов/маркеров не допускаются.

Копии сохраняют точные байты принятых защищённых исходников и их fixed source pins.
Это материалы для изучения; пути исполнения остаются защищёнными, сам перенос
файла в репозиторий не является разрешением или штатным способом запуска.

`supervisor.before-delta.py` — сохранённая прежняя версия. Финальная проверка Root
обнаружила полное сравнение native snapshot с volatile observed_monotonic;
исправленная версия — `supervisor_adapter.py`, точная дельта —
`root-caller-reviewer-fix.patch`. Root независимо проверила reviewer-fix;
23 инертных whole-caller контроля прошли. Старую before-delta версию не запускать.
Остальные source/API/custody/clock проверки переиспользованы на неизменных байтах.

`bot-tester-first-send.patch` применяется к exact base из PROVENANCE.json;
полный прежний внешний harness и приватные raw-run/proof/oracle/document/env
не копируются. `assembly.py` — чистые функции без I/O, часов и допуска.
Source, runtime, custody, содержательная и формальная приёмка остаются разными фактами.

`root_operator.py` — окончательный source-only Root caller. Финальный review
закрепляется внешним точным SHA, без циклического selfhash. Живые current-факты,
трёхкратное владение существующими locks, отдельное решение/часы и один запуск
остаются будущей обязанностью Root; source-ready их не заменяет.
