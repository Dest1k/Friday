# DOCX: неактивные копии колонтитулов — source-only

Узкий проверенный кандидат снимает отказ managed DOCX reader на избыточных неактивных first/even колонтитулах после сохранения Office. [Патч](native.patch), [точный профиль и доказательства](SOURCE-ROOT-ACCEPTED.json), [оперативная очередь](../../ASTRA-CURRENT.md).

Принимается одна конечная секция с выключенными alternate-page flags. First/even копии должны совпадать с default по модели и полной поддержанной XML-структуре/свойствам; особый пустой even допускается только в малом явно описанном профиле. Все физические stories разбираются и учитываются в лимитах до исключения копий из модели. Уникальное содержимое, активные варианты, несколько секций, неизвестные/внешние/неоднозначные ссылки и неподдержанные структуры сохраняют отказ.

На тех же сохранённых owned9418 байтах старый parser отказал, новый pure parser принимает файл; настоящий вызывающий preflight доходит до STOP-сентинела toolchain. Capability/effect leaves объявлены stub, **Office не запускался**. Исходный raw-space/inventory FAIL, malformed owned2528 и исторические Word/App/custody/full180/formal оценки сохранены. Matching text отдельно не считается доказательством сохранности свойств.

Независимое source review и Root code review приняты. Это незадействованный draft: не включён в LAYER_NAMES, ordinal не назначен, не установлен. Нужны настоящий установленный predecessor и обычный Root source/CAS/consumer/rollback/install-процесс. Старые документы и отправки не переигрываются ради PASS. Частные fixtures, payloads, handoff и сырые наблюдения не публикуются.
