Оцениваются явно переданные байты исходника, received и saved, точная числовая
правка, формулы/текстовые ID и согласованные chart/name/filter/validation/merge/
current-hidden свойства. Ожидания опираются на исходные требования и отдельные
независимые факты; кэши saved не служат эталоном. Приватные данные и эталоны в
публикацию не входят. Подробные границы поддержки указаны в интерфейсе.

Это неподключённый оценщик. Настоящие ordinary received/saved, открытие/
редактирование/сохранение/повторное открытие, custody, неизменность оригиналов,
исходные часы и приёмка исходного CASE164/F03 остаются отдельными обязательствами.
