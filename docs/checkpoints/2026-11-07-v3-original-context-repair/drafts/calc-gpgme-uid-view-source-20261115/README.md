# GpgME UID views — архив исходников

Только исходники. Зафиксированы четыре точных afterimage, четыре исходных diff и два независимых final test-source. SOURCE принят Root; это не допуск к исполнению, установка или фактическая квалификация. Installed224 и постоянные сервисы этим пакетом не изменены. На момент исходного принятия положительная OwnC-проверка и три отрицательные проверки на этом successor ещё не выполнялись.

Коллектор различает защищённое представление UID map, прочитанное Root, и собственное представление относительно родительского user namespace. Владельцы host-файлов переводятся только по защищённой HOST map. Обе map независимо разбираются; inside-domain, текущий user namespace, overflow, первоначальный self-digest и последующие CAS остаются обязательными. Основание — неизменяемая после первой записи непустая kernel UID map и точная текущая идентичность user namespace в существующем защищённом канале. Неизвестные и unmapped sentinel-представления не расширяют поддерживаемую область.

При UID-отказе разрешена одна попытка записать ограниченные числовые/digest-метаданные в точный защищённый файл; исходный отказ сохраняется при ошибке построения или записи. Root может прочитать только этот дополнительный terminal-файл после подтверждённого опустошения cgroup, с прежними FD/path/rights/CAS-проверками. Метаданные не становятся основанием допуска или новым вердиктом. Supervisor добавляет только фиксированную роль исходника и номер строки.

Зависимости уже опубликованы: [reviewed M2](../calc-gpgme-m2-reviewed-observer-source-20261115/README.md) и [OwnC caller / ENV / reader-join](../calc-gpgme-ownc-caller-env-source-20261115/README.md). Их полные стенды и неизменённые зависимости сюда не копируются; PUBLIC-MANIFEST фиксирует точные before-версии и pins. Исторический `reader-join` остаётся историей; действующие afterimage находятся в этом архиве.

[Независимые UID-контроли](review/independent_controls.final.py) содержат 11 pure source-тестов, [final consumer-контроли](review/final_consumer_controls.py) — 8. Опубликован их точный код, без повторного запуска при упаковке. В нём сохранены приватные инфраструктурные ссылки; необходимые приватные fixture/snapshot/plan-входы не опубликованы, поэтому архив не является переносимым тестовым или исполняемым комплектом. Авторский `uid_view_controls.py` целиком исключён: вместе с синтетическими контролями он содержит историческую реконструкцию raw HOST map. Его pin и причина исключения сохранены в манифесте; исходник не редактировался ради публикации.

Исходные source/review/Root pins перечислены в PUBLIC-MANIFEST. Прежние 26 авторских, 96 ближайших и 19 независимых source-наблюдений относятся к указанным private свидетельствам; упаковка их не повторяет и не выдаёт за runtime. Исторический failed UID conjunct и отдельная причина secondary runtime_file_rights остаются UNKNOWN. Actual M, Office/provider/history, физическая fidelity и full170/120/B00 остаются OPEN.

Не включены private исходные результаты/логи, raw memory/maps, фактические numeric HOST witness, планы, grants/ONCE, SOURCE-COMPOSITION/SELECTED/PREPARED, runtime templates, документы, DB, binaries или credentials. Известные инфраструктурные пути в коде/diff сохранены. Строки diff, состоящие из одного пробела, являются исходными context-prefix и должны остаться побайтово точными. Публикацией и дальнейшей live-интеграцией управляет Root.
