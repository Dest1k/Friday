# EML: обычная Subject-copy EDIT на226 — Source

Исходное обязательство: F03/CASE164, format108 EML, FX-FMT; правка ранее
полученного файла в том же формате с сохранением исходника и остальных данных.
Поддержан уникальный верхний Subject и отдельная выходная копия. Тело, MIME и
вложения не редактируются. Установка227 для этого неизменённого nativeEDIT пути
не требуется; CREATE остаётся отдельным будущим обязательством.

Библиотека и оба ROOT_UNBOUND образца — проверенные исходники, без authority,
current admission, once или runtime-результата. Генераторы требуют точные старые
Code зависимости по SHA; сам архив не предоставляет допуск и не запускается.
Root отдельно закрепляет настоящий received/receipt/native join, профиль226,
историю и свежие изменяемые условия. Full ordinary pre-save/current gate, locks,
CAS, stop и600/480/900 бюджеты сохранены. Future output/delivery оцениваются после
операции, по тем же возвращённым байтам с artifact_checks.verify_edit.

[Манифест](SOURCE-AND-REVIEW.json) содержит pins и проверки. Унаследованный current
остаётся наблюдением в момент проверки; это не атомарный снимок всех БД/политик.
100MiB — наблюдаемый рост/проверка записи, не hard filesystem quota;512MiB — AS.
Исторический EML firstREAD2804→2808 WHOLE FAIL и ограничения повторов сохраняются.
Source, исполнение, семантика, App и формальная приёмка — отдельные факты.
