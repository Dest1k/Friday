# Исправление проверяющего rich RTF — source only

в обычном StarBasic и потерю ошибки/остановки в активном error handler.
Используется mapped `Error5` с отдельным guard ID и новый cleanup frame.
Это QA-макрос; native RTF R4 и частный компонент afba не изменены.

Проверены52 source/mutation/profile-byte controls и независимая дельта; области перекрываются.

до InitOnly, документы отсутствуют; успешный callback того же неизменного модуля должен
подтвердить реальную компиляцию и COMPONENTS0 до копирования сохранённой пары.
Затем только один readonly Main под прежними180s/CPU120/Main75/4GiB пределами.
Этот файл не является допуском или готовым запуском.

канонический FXDOC, LIVE_BOT, формальную приёмку и полный V3.
