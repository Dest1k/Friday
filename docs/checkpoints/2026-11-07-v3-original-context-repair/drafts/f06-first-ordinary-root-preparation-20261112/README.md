# F06: подготовка первого ordinary wrong-read, исходники и review

Статус архива: `SOURCE_AND_PREPARATION_REVIEW_ONLY`. Сохранены девять новых файлов точными байтами; [MANIFEST.json](MANIFEST.json) задаёт происхождение, размер, SHA-256, область свидетельства и предложенный путь публикации. Снимок репозитория: `aef7541d558b9072370c748412b11757d7b8000c`. Пакет относится к существующему ordinary207 пути. [Ранее опубликованный source207](../f06-ordinary207-source-20261112/README.md) используется по ссылке, без дублирования его файлов.

- [Constructor/core-memory и корни](files/constructor-roots/RESULT.json), [выбранные безопасные метаданные и фрагменты исходников](files/constructor-roots/SOURCE-BASIS.json), [исходник их коллектора](files/constructor-roots/collect_readonly.py).
- [Независимое review подготовки](files/independent-review/RESULT.json), [статические свидетельства](files/independent-review/STATIC-EVIDENCE.json), [отдельное review lineage/privacy](files/independent-review/lineage-subreview/RESULT.json).
- Исходники Root: [подготовка фактов](files/root-helpers/prepare-first-ordinary-f06-facts-20261112.py), [binder с точным проверенным пином](files/root-helpers/bind-first-ordinary-f06-20261112.py), [postcollector](files/root-helpers/collect-first-ordinary-f06-saved-result-20261112.py). Последний сохранён как `UNREVIEWED_SOURCE_ONLY`: его исполнение и результат этим архивом не подтверждены, область имеющегося review его исключает.

Constructor/core-memory вывод относится к обычному non-proxy source/config пути: default manager=None и core sentinel, выбранные all3 поля конфигурации, enclosing product-file root [H]. Это ограниченный вывод по источникам и выбранным метаданным; объект живого manager и глобальное отсутствие сохранения секретов не наблюдались. Частные абсолютные пути, profile-home имена, размеры/хеши, inode/PID и временные метки сохранены как выбранные метаданные происхождения. Сами конфигурации, содержимое профилей и живое состояние отсутствуют.

Исторический установленный206 pure-leaf результат остаётся `7/8 FAIL` с исходной ошибкой. Исправленный проверяющий benign normalization-warning не превращает его в полный PASS. Полный runtime-wrapper остаётся `WARN_NOT_RUN`; scoped native205 overlay, установленный206 и retained207 codec — разные факты. Исходный generation/client/oracle FAIL g6, `NEVER_ISSUED` и M14 UNKNOWN сохранены в выводах review. Standard3.2 остаётся без MAC: `data_integrity_verified=false`.

Review принимает подготовку и точные пины, сохраняя final admission, current/CAS, clock/once/slot, cancellation и реальные общие эффекты за Root. При упаковке выполнены только сверка SHA/размеров, JSON/AST parse, проверка ссылок, отсутствие дублей прежнего U и ограниченный поиск распространённых форматов секретов. Исходные collectors/binder, модель, Telegram, Office, сервисы и установка этой задачей не исполнялись. Секретные значения для exact-value поиска задача не читала; такой поиск по фактическому пользовательскому результату остаётся у Root.

После подготовки Root сообщил: driver закрыт `prebirth` после issuer; consumer, upload, модель и ответ не запускались. Интеграция отказала в `f06_source.contract_shape`: статически проверенный источник ожидал F06-префикс authority ID, а фактический native `derive_identity` сохранил F04-подобный префикс `ordinary-f04-postfix-diagnostic-20261112-r106` при точных F06 scope/run и scenario. Это позднейший отказ интерфейсной совместимости, сообщённый Root; ранние исходники и preparation review сохранены неизменными и не превращаются в успешный пользовательский прогон. Санитизированное свидетельство фактического отказа и закрытия Root публикует отдельно; задача упаковки его не читала и не принимала повторно. Семантический ответ и полный F06 PASS отсутствуют.

Здесь отсутствуют документы и chat bodies, supplied password/credentials, `SCENARIO.private.json`, весь живой каталог O, реальные grants/authority/proofs/clock/once/admission, raw native history и журналы. Ссылки на частные пути внутри неизменных файлов обозначают происхождение и не разрешают повторение уже совершённых эффектов.

Архив предназначен для анализа. Он зависит от прежнего опубликованного source207, защищённых входов и доказательств Root, установленного runtime/native и существующей среды; самостоятельный воспроизводимый запуск из этих файлов не заявлен. Проверка установки, подключение, runtime, пользовательский ответ и семантическая приёмка остаются отдельными фактами.
