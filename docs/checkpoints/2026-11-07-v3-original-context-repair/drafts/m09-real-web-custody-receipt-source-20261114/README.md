# M09: настоящий web custody receipt

Проверенный source-only patch для установленного215. Настоящий `web_custody_readonly()` возвращает обёртку с `receipt`; M09-наблюдатель ошибочно проверял `status` на верхнем уровне и отказывал даже при пустых ресурсах. Дельта выбирает настоящий `receipt`, как существующий ordinary consumer. Проверки статуса, сессий, recovery, делегаций и leases не ослаблены; counts0 не заменяют quiescence.

16 собственных и46 независимых source-контролей включают настоящий интерфейс producer, пустую/непустую custody, recovery и malformed/unknown отказы. Полного native dispatch/установки/runtime/M09-пользовательского PASS ещё нет. Это не штатный layer-manifest: точную216-композицию/происхождение/CAS/consumer/rollback готовит Сол, устанавливает только Root после актуального допуска. Действующие сервисы215 работают.
