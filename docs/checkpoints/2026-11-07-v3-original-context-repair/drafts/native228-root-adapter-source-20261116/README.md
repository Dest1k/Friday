# Root228 operational constructor — Source

Архив точного конструктора из проверенного R2. Он строит отдельный Source
sibling по закрытому R5 Code и новым Root selector refs; прежние операции,
clocks/authority/ONCE не переносит. 195 функций сохранены по AST. Ошибка
миграции Global/Nonlocal исправлена и отдельно проверена. R1generator после
локальной ошибочной записи восстановлен до исходного pin; R1records неизменны.

Это **Source**, не установленный адаптер или runtime-допуск. Реальный builder
уже принял полный14-полевой input с13 сохранёнными значениями, настоящий
predecessor227/v29 и explicit новый слой/v30. До установки ещё необходимы
Root descriptor+полный pin freeze, настоящий ближайший caller preflight,
свежие предпосылки и отдельное maintenance-исполнение. Postconsumer и новые
canonical outputs проверяются после той же транзакции.

[Проверки и pins](SOURCE-AND-REVIEW.json). Конструктор здесь — frozen Code archive;
его относительные OWN/R1 dependencies относятся к согласованному приватному
Source-стенду, запускать архив как installation command нельзя. Raw input,
actual8, ABI/private handoff, generated frame и runtime records не опубликованы.
SourceOrigin productc1cb и executionOrigin содержащего операторского checkpoint
имеют отдельные роли; хеш коммита внутрь самого себя не записывается.
