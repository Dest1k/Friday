`assess_conversion` accepts only explicit immutable bytes and JSON data:

- `source_ods_bytes`: selected original ODS or a future independently eligible selected source. Selection remains Root's responsibility.
- `returned_xlsx_bytes`: the actual candidate bytes. No output or expected workbook is generated.
- `authority_xlsx_bytes`: the original selected feature authority, distinct from a conversion observation.
- `request`, `projection`, `oracle`, `pins`: exact-key bound data described by the schemas. `pins` joins SHA-256 of all three blobs and canonical JSON of all three objects.
- `libraries`: explicit source bytes at every pinned `LIBRARY_PINS` digest. Legacy `main`, `context`, old private oracle, filesystem provider and Office code never execute. Only selected pure definitions are extracted from the structure and strict modules.

Canonical JSON is UTF-8, sorted keys, no whitespace, `ensure_ascii=False`, `allow_nan=False`. `bind_profile` prepares private source-derived request/oracle/projection in memory for review or later independent commitment. A matching hash never proves authority, custody, source eligibility or oracle independence.

The fixed profile checks all three sheet names/order, every populated coordinate, all literal values/types, four text IDs, four genuine multiplication formulas and the cross-sheet summary graph; selected custom name/scope/range, filter predicate, validation locations/stop/error behavior, all merges, current hidden sheet/row/column visibility and attached chart references/title/type/visible-only behavior. Arithmetic is Decimal from source quantity and price literals. The graph is not a generalized Office evaluator.

If present, all five formula caches and every selected chart cache point must equal the independent source-derived semantics. Missing caches remain visible as `SELECTED_STRUCTURE_MATCH_WITH_CACHE_GAPS`, with missing counts. This is not a conversion PASS. `SELECTED_REQUIRED_BYTES_MATCH_SOURCE_PROJECTION` means the finite selected byte checks matched; all external authority, runtime, independence, ordinary, formal and whole-conversion flags still remain false.

The original authority itself has five formulas with empty caches and no chart point caches. Its text-ID category uses `numRef` with no cache. This spelling is retained as an explicit cache gap; present numeric category caches cannot establish text-ID label fidelity and are refused as unsupported. It is an existing source-only structure-positive test vector with cache gaps. No synthetic complete positive workbook may be substituted for actual future conversion bytes. Wrong-data/formula/richness controls mutate that existing vector only in memory.

The four known losses, four UNASSESSED observations and nineteen dimension-history observations are retained as history counts without any restoration claim. Vendor metadata, freeze/header-band/page geometry, physical dimensions and hidden filter/collapse provenance are not promoted. Original authority vendor table parts are counted as explicitly unassessed; their presence cannot establish restored ODS-source history. Unknown package parts and worksheet children are refused. Numeric source chart caches may be stale, but exact visible category-row lineage and dimensions remain checked. Runtime save/recalculation/reopen, ordinary delivery, authenticity, nonreplay, current admission and final semantic acceptance remain external, UNBOUND Root joins.

Results contain fixed codes, counts and digests only. Private request/oracle values, paths, workbook text and formulas must never be printed or published. Generic code/schema files have no fixture paths and may be considered separately for a sanitized publication allowlist.
