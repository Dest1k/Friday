# Точный entry и диагностика fork-birth: только SOURCE

Архив содержит ровно два изменённых afterimage, два побайтово точных diff и семь
новых исходников проверок. Код принят Root только в области SOURCE. Упаковка
не выполняет импорты или тесты и не переоценивает предыдущие проверки.

`gpgme_engine_gdb.py` исправляет точный вход: адрес `gpgme_get_engine_info`
разрешается без вызова функции, breakpoint ставится на числовой адрес. Исходные
owner/map/offset/bytes и lifecycle guards сохранены. Последующий actual42fa
отказал на birth guard; исправление entry не означает успех всей цепочки.

`gpgme_boundary_collector.py` добавляет только однократную ограниченную числовую
диагностику первого отказа из уже прочитанных значений и traceback. Исходный
guard и терминальный отказ сохранены. **Семантический fork-ремонт отсутствует;
квалификация не готова.** Известный дефект pending-inferior остаётся открытым.
Root не запускает новый полный actor только ради атрибуции при этом дефекте;
отдельный семантический SOURCE-ремонт ведёт Сол в своей существующей сессии.
Конкретные PID, conjunct и callsite закрытого actual отказа остаются UNKNOWN.

Точные предшественники переиспользуются по относительным ссылкам и SHA:

- [M2: исходный adapter](../calc-gpgme-m2-reviewed-observer-source-20261115/candidate/outer/deps/gpgme_engine_gdb.py)
- [UID: исходный collector](../calc-gpgme-uid-view-source-20261115/candidate/outer/deps/gpgme_boundary_collector.py)

Остальные неизменённые исходники и весь stand повторно не копируются. Связи
before/after/diff и SHA указаны в [манифесте](PUBLIC-MANIFEST.json); точные pins
частных source-evidence — в [SOURCE-PINS.json](SOURCE-PINS.json). Текущий предел
приёмки указан в [SOURCE-STATUS.json](SOURCE-STATUS.json).

Проверки сохранены как точный исходный код в `entry/` и `birth/`; числовые данные
фикстур синтетические. Инфраструктурные пути и исходные обращения сохранены.
Скрипты перемещены, зависят от исходной структуры и частных metadata/fixtures и
**не являются самостоятельным набором для запуска**. Некоторые выполняют
`exec` и запись результатов при импорте; архив их не запускал. Прежние результаты
приведены как pinned SOURCE-свидетельства, без runtime или продуктового credit.

Installed224 не изменён. Genuine M, provider/history/fidelity, fullV3, full170,
120 и B00 остаются OPEN. Закрытые эффекты, ONCE и часы не переигрываются.

Не включены raw runtime values, пользовательские документы, память/maps/трассы,
логи, ключи/секреты, планы/grants/ONCE, SELECTED/PREPARED/composition, runtime
шаблоны, DB, бинарники и исходники GNU upstream. Точные файлы не редактировались
ради публикации; одиночные пробелы контекста в diff сохраняются побайтово.
