# F06/F05: настоящие типы OTT, OTS и OTP в native203

Малые собственные синтетические шаблоны имеют соответствующие template MIME
и text/spreadsheet/presentation body, а не переименованный ODT. Независимый
cryptography oracle проверяет CBC/PBKDF2, ZIP/XML, требуемую правку и инварианты.
Продукт использует свой реальный native scoped read/edit и Cryptodome.

OTS/OTP: реальные missing/wrong/correct read/edit, source SHA, no-replace,
encrypted output/read и сохранение исходника приняты в ограниченном профиле.
OTT: первая правка завершилась, затем сломался stand; raw edit/negative receipts
не сохранились. Файл сохранён и не пересоздан. Новая конечная операция проверила
только недостающие readonly/oracle части и ещё не начатые OTS/OTP. Потерянные
receipt/контроли OTT не восстановлены предположением. Initial source сохранён.
Ошибка nested principal и точный missing scoped_odf_review pin исправлены только
в stand; native guards не менялись. V2 сохранял receipt после вызова и реальные
времена операций; отдельного pre-effect intent journal не было.

Root проверил579 pins/условий и использовал независимый финальный source-review;
это не579 пользовательских кейсов. Процессы закрыты. Actual Office validity,
ordinary bot, формальная F06 и весь170/120 не приняты. Следующий App-кандидат
готовится отдельно и не даёт права повторять native/OTT edit.
