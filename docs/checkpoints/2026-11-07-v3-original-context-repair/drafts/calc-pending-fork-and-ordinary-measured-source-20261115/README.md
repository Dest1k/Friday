# Conditional pending fork and ordinary measured Calc — SOURCE archive

Три раздельных результата на снимке `2e5bd11c7da19c478bd3e54efc65cc2a1b722bd1`:

- **Sol, 7 файлов:** Root принял точный условный pending-fork SOURCE protocol.
  Нужен отдельный уже принадлежащий операции остановленный selector на каждом fork;
  при его отсутствии путь отказывает. Это не runtime-квалификация GDB или startup.
- **G2, reviewed PARTIAL:** конкретные same-model inner, native joins и parent cut:
  полное восстановление Font → live join → один stock store; после чтения output
  один canonical D6 context передаётся двум consumers. Полная native factory,
  supervisor, managed assets, helper/font/terminal custody ещё отсутствуют.
- **Root common layout R2:** только staging/identity/exact tree и pure namespace argv.
  R1 был отклонён с тремя findings; fixture PermissionError и исправление checker
  сохранены в [истории](layout/HISTORY.json). Первоначальный integration PASS не заявлен.

**Не установлено, не включено, не runtime-ready. Actual M отсутствует; G2 COMPLETE,
product/case PASS, physical fidelity и пользовательская приёмка не получены.**

`layout/candidate-r2` и checker сохранены побайтово. `LAYOUT-R1-TO-R2.patch` получен
из pinned R1/R2 без изменения исходников. Checker — архивный код с исходным
именованным cache dependency; здесь он не запускался. Пакет не самодостаточен:
точный unchanged fresh wrapper имеет только pin; старые опубликованные wrappers
отличаются и не подставляются. Fixed factory interface — отдельное требование,
а не готовая реализация. Схемы/хеши не подтверждают native факты.

Проверки этого архива ограничены целостностью копий, diff/context/space bytes,
относительными public ссылками и независимым publication/privacy review. Исторические
SOURCE controls не выдаются за новые прогоны. Product imports/tests, GDB/Office,
namespace, model, render, install, send и старые операции не выполнялись.
Старые consumed effects/clocks и UNKNOWN не переигрываются.

В опубликованных executable afterimages ничего не редактировалось ради приватности:
сохранены исходные generic operator/cache literals. Private fixtures, документы,
логи, credentials, runtime grants/plans/bundles, binary assets и GNU upstream code
не включены. Root отдельно владеет интеграцией, новой квалификацией и Git publication.
