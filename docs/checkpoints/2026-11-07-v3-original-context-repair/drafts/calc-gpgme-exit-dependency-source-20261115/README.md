# GPGME exact exit dependency profile — SOURCE only

This sibling successor archives two exact changed Python files and the original
patch. The unchanged native observer, paper helper and OwnC driver are reused by
[exact public predecessor references](SOURCE-DEPENDENCIES.json). It is a
nonstandalone conditional source proposal. It is not installed or enabled;
runtime, liveness, actual M, formal, semantic and user acceptance remain unqualified.

The collector keeps the exact ELF entry dependency closure. At the final helper
`exit_intent` boundary it binds a separate exact C.UTF-8 profile of fourteen
read-only passive locale/gconv files. All five currently supported present
branches are covered: gpgconf list_dirs/list_components/gpgconf_version,
gpg_version and gpgsm_version. g13 remains absent; no profile is fabricated.
The adapter supplies the explicit phase and branch at the existing final-child
exit-intent check. Other adapter methods and the fork/custody/guard flow retain
their bytes.

The full absolute mapped-path set must equal the original ELF closure plus that
exact passive set. Missing, extra, swapped or alternative mappings still refuse.
The original load-boundary rule remains unchanged; there is no new generic
subset allowance. Passive files retain exact backing identity, hash, UID
projection, read-only permissions, mapping extent and final CAS checks. The
profile models successful locale initialization; a failed or partial setlocale
can legitimately fail closed. Static source support provides no runtime or
liveness credit.

[EXIT-INTENT-MAPPINGS.json](EXIT-INTENT-MAPPINGS.json) contains only the exact
`collector_pins.exit_intent_mappings` field extracted from the pinned private
manifest. The original JSON value bytes are preserved. It has fourteen root-owned
system-file stamps/hashes and fixed source metadata. It is **not a standalone
manifest or runtime admission object**. The full private manifest is pinned by
reference only; its environment, process/UID projection witnesses, remaining
fields and runtime plans/grants/bundles are excluded.

Apply [the original patch](EXIT-DEPENDENCY-PROFILE.patch) to isolated copies of
the exact public beforeimages using the role/header mapping in
[dependencies](SOURCE-DEPENDENCIES.json). Absolute patch headers remain exact
provenance and are not live destinations. All context bytes, including single-space
blank context lines, are preserved. Reconstruction requires zero fuzz and zero
offsets and yields the two archived afterimage hashes.

[Primary metadata](PRIMARY-SOURCE-METADATA.json) records source URLs, package/hash
and line ranges, without copying upstream source or binaries.
[Source status](SOURCE-STATUS.json) pins the existing independent source review,
static proof and controls. Archive verification covers copies, patch, AST and
public link/hash integrity. It does not import or execute product code.
[The public manifest](PUBLIC-MANIFEST.json) excludes itself.

Old b450/6c/7d8/5bb effects and clocks remain closed. Their actual extra/missing
maps were not saved and remain UNKNOWN; this profile does not attribute those
refusals retrospectively. The ordinary factory remains independent work and is
not an OwnC prerequisite. Root alone owns integration and any separate finite
admitted current runtime qualification. This archive creates no runtime
prerequisites or authorization.
