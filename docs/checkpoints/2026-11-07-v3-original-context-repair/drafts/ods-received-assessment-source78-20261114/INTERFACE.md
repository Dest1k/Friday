# Received ODS byte assessment

`received_ods_checker.py` is a pure finite assessor of existing bytes. It imports only Python standard libraries and the adjacent `preservation_helpers.py`. The latter contains unchanged AST-selected functions and constants from the pinned, previously reviewed preservation suite; `PROVENANCE.json` pins every selected source slice. No product package, editor, model, Office, runtime, network, path reader, producer, fixture generator, or authority mechanism is invoked.

```python
assessment = assess_edit(source_bytes, received_bytes, request, binding)
```

Both byte arguments must be immutable `bytes`. `request` is exactly a dictionary containing `sheet`, `cell`, `expected`, and `value`, all strings. The sheet identity and uppercase A1 reference select the actual target; there is no default sheet/cell. `expected` must exactly match the source numeric attribute, including its lexical representation. `value` must exactly match both the received numeric attribute and displayed paragraph. Both numbers must be finite bounded decimal strings. A request must change numeric value, not only representation. The source target must be an unprotected, unrepeated, unmerged numeric literal with one plain paragraph; any existing paragraph attributes, including text identifiers, survive. The known whole-number/between validation form is enforced when bound to the target; other validation languages refuse with a fixed reason code.

`binding` contains mandatory lowercase SHA-256 strings `source_sha256`, `received_sha256`, and `request_sha256`. Compute the last with `request_sha256(request)`, which hashes ASCII JSON with sorted keys, `ensure_ascii=True`, and separators `(',', ':')`. Optional `source_custody_ref`, `received_custody_ref`, and `operation_ref` are opaque text references or `None`. They are never resolved or echoed and provide no authority. Unknown request/binding keys refuse; a trust/scope label cannot promote a retained sample.

A successful assessment has `status` and `code` equal to `EDIT_BYTES_MATCH`, meaning only that supplied bytes match the pinned request. A refusal has `status='REFUSED'` and one fixed code. No workbook, reference text, values, formulas, or sheet name is included in the result. Counts, hashes, the requested cell reference, and fixed reason codes may be returned. This checker never returns user-acceptance `PASS`.

Every result states `scope='supplied_bytes_only'`, `authority_verified=false`, `ordinary_delivery_or_user_acceptance=false`, and `new_effect_authorized=false`. Source custody, received custody, installed version, and nonreplay verification are also always false. Canonical custody, ordinary ingress, delivery, installed version, nonreplay, and user acceptance remain explicitly `UNBOUND` external Root joins. Even matching fixture pins plus arbitrary custody tokens cannot establish any of these facts. The assessor is neither product admission nor a provenance authenticator.

The preservation check compares all content XML bytes before and after the selected physical cell, every other ZIP member payload, the member set, and all target attributes except numeric value. The selected display paragraph may change only its numeric text; other target text/tails and display metadata stay identical. This preserves raw formulas, types, text identifiers, validation definitions and identity, chart payloads/identity, names, filters, merges, current hidden state, and every non-target cache. ZIP compression and metadata are not claimed byte-identical. Formula caches are explicitly `preserved_not_recalculated`; freshness is neither required nor claimed before independent App assessment.

The bounded package parser rejects duplicate or unsafe member names, symlinks, encryption, unsupported compression, a missing/non-first/compressed ODS mimetype, oversized input/member/expanded payloads, malformed ZIP/XML, DTD/entities/processing instructions, excessive XML depth/elements, and non-ASCII-compatible XML encodings. Public constants define finite bounds: archive 32 MiB, member 16 MiB, expanded total 64 MiB, 512 members, 100000 elements per XML member, depth 128, 256 sheets, and a logical row/column/repetition ceiling of 1000000. Numeric strings are at most 512 characters with adjusted exponent magnitude at most 300. These are assessment bounds, not broader format-support claims.

The independent App adapter may use `inspect_ods(bytes) -> ArchiveSnapshot`, with `payloads`, safely parsed XML `roots` keyed by member name, `raw` content bytes, `root`, `body`, and `sheets`. `locate(snapshot, sheet, cell)` returns the selected `node`, physical `row`, `sheet`, and byte `span`, subject to the same numeric-target restrictions. These structures contain private workbook content and must never be logged. `CheckError.code` is a fixed reason code. `sha`, namespace constants, and unchanged helper functions are public for that narrow pure adapter seam. Inspection creates no files or processes.

Future App preparation must start from the very same independently retained received SHA, operate only on a disposable copy, bind its controlled additional change separately, and use a separately supplied private independent Root oracle. This edit checker neither derives formula answers from afterfile data nor supplies oracle values. A byte assessment is not permission to recalculate or replay any effect.

The private source-only tests exercise the new assessor against unchanged retained originals and existing edited samples, plus malformed, wrong-delta, lost-formula, cache, non-target, metadata, scope-spoofing and pin-binding controls. They do not rerun the previous product suite and do not provide ordinary received, live, delivery, installed, or user-acceptance credit.
