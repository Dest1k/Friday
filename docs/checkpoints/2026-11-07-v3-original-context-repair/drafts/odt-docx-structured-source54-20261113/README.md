# Structured ODT→DOCX: source54

Проверенный исходный кандидат для F04/CASE165. Он расширяет строгую семантическую
модель конвертации: native список, сноска с Unicode-якорем, связанные header/footer,
заголовки, таблица, версия и явный разрыв страницы. Сравнение и hash охватывают эти
структуры целиком; обычный plain-профиль сохранён. Неизвестные графы и потери дают отказ.

`SOURCE.patch` меняет один native-файл; точные before/after SHA и границы — в
`MANIFEST.json`. Кандидат **не подключён и не установлен**. Реальный Office,
установленный пользовательский путь, полученные байты, App и формальная приёмка
ещё не выполнены. Независимый синтетический DOCX использовался только в source-тестах.

Root должен выбрать действительный следующий prefix, проверить его preimages,
композицию, consumer, CAS и откат, затем отдельно провести предусмотренные Office
и обычные проверки. Исторические отправки/Office-циклы не повторять ради PASS.
Приватные исходные документы, fixtures и oracle в публикацию не входят.
