# Структурная ODT→DOCX: восстановление результата по исходному документу

Реальный Office сохранил структуры, но добавил разрыв перед первым абзацем и TAB
в начало текста сноски. Исходный raw DOCX8991B остаётся `semantic_mismatch`.

Кандидат сравнивает полные модели исходника и raw-результата. Только эти точные
добавления разрешают отдельную правку native XML в рабочей копии. Все прочие
данные, порядок, namespace и авторские TAB сохраняются. Полная проверка проводится
повторно до прежней create-only публикации. Производный DOCX8791B имеет отдельный
SHA; неизменный oracle сравнивается целиком. Новый Office не запускался.

`SOURCE.patch` меняет два native-файла. Точные preimages/результаты — в
`MANIFEST.json`. Код независимо проверен, **не подключён и не установлен**.
Пользовательский путь, native authorization, App/визуальная проверка и формальная
приёмка ещё не выполнены. Приватные документы и oracle не публикуются.
