Три файла скопированы побайтово из проверенного Source-пакета: `builder_core229.py`
определяет чистую сборку, `binding229_core.py` проверяет переданную Root основу
установки, `assemble229.py` собирает приватный конструктор из закреплённых Source.
Это публичная алгоритмическая часть. Полный конструктор `fa7ea338…445e` сохранён
локально: встроенные шаблоны содержат конкретные идентификаторы маршрутизации.
Публичный набор требует локальных закреплённых шаблонов и Source-параметров.

Целевая основа: 229/project539/native17896/plugins52/base17730; 6MOD1ADD,
13 выбранных CAS, 17889 сохранённых записей. Замыкание включает 23 Source-роли,
восемь текстовых ролей и все семь новых native pins. Root после реальной установки
передаёт настоящие receipt/marker/stamp/input, закрытие, Source acceptance, Python

требует адресной проверки. Наблюдения optional Source capture сохраняют реальный
статус, включая unavailable/partial.

61 проверка изменённой области и 85 независимых контролей относятся к Source.

вызывающего пути на установленной версии, итоговое bound-review, свежий допуск
и исходная пользовательская операция с оценкой полученного HTML. Требуется
наблюдаемый native `read_file`; автоматическое включение HTML в запрос этого
не подтверждает. `text_edit` предоставляет literal-copy, свойства DOM/render
и полная fidelity оцениваются отдельно по исходному контракту.
