Native archive families

The ordinary scoped file route gains TAR and gzip/bzip2/XZ/Zstandard-compressed TAR creation, a paginated member registry, extraction to a new directory and conversion between supported ZIP/7z/TAR containers. Common shorthand suffixes are recognized. Member names and payload bytes are preserved; unsupported link/device/sparse records refuse.

Single-file gzip/bzip2/XZ/Zstandard compression is a separate operation. The file is compressed without an archive; its extracted name comes from the compressed basename minus its final suffix. Embedded header filenames cannot choose an output path. Concatenated streams, trailing bytes, unsafe names and over-limit expansion refuse. The same bounded ZIP helper now protects ordinary ZIP inspection and nested secret scanning.
