# OneNote and Publisher native stored-text reading

Source149 adds bounded native reading for desktop OneStore v42 `.one` sections and supported Publisher `.pub` Contents/Quill records. Ordinary own-workspace reads retain source identity, pagination and explicit partial coverage. OneNote resolves committed current revisions and refuses conflicting/deleted or unsupported content; cancellation and cumulative reference limits remain active. Publisher reports stored story/page relationships and preserves untrusted-content labels.

This is source-only preparation. Installed Source117 and permanent services are unchanged. Rendering, full-format validation, attachments, encryption, OneNote packages, and writing these formats remain unsupported. Live Telegram and user-semantic acceptance have not run.

The package includes OneNote reviewer fixes and both required MPL license sets. Separate kernel review and current-source integration checks include meaningful refusals and preserved Access/HEIF/EPUB/VDX/XPS/ODG/XLSB routes. An intermediate local merge dropped earlier write-schema additions; the integration check caught it, the merge was repaired, and affected checks passed on the final source. Historical failed observations remain in private working evidence.
