# Native ODT source package

The scoped file path now reads native ODT/OTT, creates native ODT paragraphs, headings, lists and tables, and edits one unique literal occurrence in a supported ODT paragraph into a new file. Plain-text overwrite of ODT/OTT is refused. OTT is read-only.

The patch is against the uninstalled Source120 snapshot identified in `MANIFEST.json`. This publication contains source and local observations; it does not install the change or establish runtime, Telegram delivery, visual fidelity or full-product acceptance.

The editor retains XML outside the selected lexical text slots and the payload of every other archive member. It uses the existing source identity checks and atomic create-only publisher. Mixed formatting, fields, anchors, tracked/signed/active content and unsafe references refuse. Reading exposes bounded native text structure and separate notes; it does not evaluate fields or render images and layout.

`OBSERVATIONS.json` separates the 39 focused tests, 559 creator assertions, independent source review and Root's 39-test check after merging shared routing with the pending presentation changes. Review fixed allocation bounds, active-content admission and directory-payload preservation. Earlier observations remain in the working evidence.

The Hermes-derived source retains the existing MIT licensing and attribution in the repository. Private inputs, handoffs, runtime identities, logs and credentials are not included.
