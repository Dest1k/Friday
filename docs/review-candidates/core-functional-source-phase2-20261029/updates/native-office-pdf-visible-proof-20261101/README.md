Bounded native Office PDF verification source

Two reviewed modules are prepared for future ODT/XLSX/ODS PDF export integration. They are not connected to the installed product by this publication. The oracle checks source text, scalar cells and supported formula results against the rendered PDF; it does not infer correctness from PDF alternative text.

The renderer admits a restricted passive PDF profile, proves embedded glyph outlines, metrics and hint programs against exact trusted local fonts, and checks visible paint against extracted text. The new one-byte TrueType path and Noto subset handling passed local checks and 54 independent combined controls. Three one-byte/CID raster pairs were identical.

General Office compatibility remains unqualified. Non-equivalent Liberation subsets, unsupported graphic paint and other unproven profiles are refused. No Office export, installation or Telegram execution occurred in this source block. Existing installed Source117 remains unchanged.
