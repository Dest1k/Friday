# Source138: SVG, MSG and Visio native paths

Adds bounded static SVG reading, basic shape creation and a new-copy text edit that preserves all other bytes; inert MSG stored-property reading; partial binary VSD v11 reading; and additional Visio OPC page/master profiles. The VSD reader carries its MPL-2.0 license as a required source asset. PDF text placement gains bounded positive diagonal scaling while retaining existing paint/font restrictions.

The exact composition passed 35 combined local native checks and one source build with 165 layers, 115 native files, 12 changed/new leaves and 53 preserved helper signatures. Independent final review is pinned in OBSERVATIONS.json. The full native composition is source-only; the operating installation remains Source117.

Read the limitations in OBSERVATIONS.json before using these paths. Stored text and object records do not establish visual completeness, safety to open, or full-format support. The PDF raster diagnostic failure is retained. Installation, real Telegram interaction and user-semantic acceptance remain separate work.
